Supported Bible Formats

Liturgia can import Bibles from the following file formats:

  • JSON — thiagobodruk/bible array format
  • Zefania XML — .xml files with <BIBLEBOOK> structure
  • USFX XML — .xml or .usfx (eBible.org downloads)
  • ZIP — import the .zip directly; the app will detect and extract the Bible data
  • OSIS XML — .osis files
  • USFM — .usfm / .sfm text marker format
  • TSV — tab-separated: book, chapter, verse, text columns
  • Plain text — one verse per line: Genesis 1:1 In the beginning...
